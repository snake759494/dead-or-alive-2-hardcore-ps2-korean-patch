# 기술 설명

## 디스크 구성

| 경로 | 내용 |
| --- | --- |
| `SLPS_250.26` | 실행파일(ELF, LBA 1572714). 가상주소 = 파일 오프셋 + `0x1FF000` |
| `ROM_00.BIN` | 게임 데이터(LBA 1575031). 텍스처 팩·글꼴·프로필 |

바뀐 데이터는 모두 원래 크기 안에 들어가므로 파일 배치와 ISO 크기는 원본과 같습니다.

## 문자열 (실행파일)

- 텍스트는 실행파일 `0x42C000~0x480000` 구간의 SJIS, NUL 종료 문자열입니다. 대부분 데이터 포인터로 참조됩니다(`tools/extract.py`).
- 한글 음절은 SJIS 한자 코드 `0x889F`부터 1:1로 매핑합니다(`tools/enc.py`). ASCII는 전각으로 바꾸고 공백만 반각 `0x20`으로 둡니다. 제어 코드(`%s`, `%d`, `$-n`, `@-n`, `#X`, `\n`)는 그대로 둡니다.
- 포인터로 참조되는 문자열은 원래 슬롯들을 이어 붙인 빈 공간에 다시 배치하고 포인터를 고칩니다. 포인터가 없는 고정 슬롯은 제자리에 씁니다(랭킹 슬롯 용량 0x40).

## 시스템 글꼴

- 코드표: ELF `0x2C2658`(VA `0x4C1658`), BE16 SJIS. 조회는 바이트 단위 선형 탐색이며 0에서 멈추므로 빈 칸은 `0xFFFF`로 채웁니다.
- 텍스처: `ROM_00.BIN +0x7767A80`, PSMT4, 16px 칸. 픽셀은 헤더 +0x70(GIF IMAGE 태그 뒤)부터입니다.

## 커맨드 리스트

- 기술명 행 문자열 `0x46D3B8~0x46E230`, 행 포인터 목록 `0x426128~0x426310`, 캐릭터 ID별 목록 포인터 표 `0x426310`(26개).
- 캐릭터마다 기술명에 쓰는 글자만 담은 아틀라스가 있어, 한글 글자 목록과 아틀라스를 캐릭터별로 다시 만듭니다(`tools/moves.py`, `tools/tgs.py`). 아틀라스 픽셀은 +0x80, 인덱스 0 = 흰색, 15 = 검은 배경.
- 조건 설명은 그림입니다. 좌표표 `0x426378~`의 레코드 (id, w, h=24, x, y; x·y·w는 2배 단위)를 고쳐 갈무리11로 다시 그린 문구를 아틀라스 빈 곳에 채워 넣습니다(First-Fit Decreasing, 넘치면 Condensed).
- 분류 제목: 공용 팩 `0x7A46000` 항목 14, 28px 띠 8개(위→아래 그라데이션).

## 프로필

일본어 팩 `0x71C6800` 안, 헤더 `0x71C8B70 + k×0x8140`, 픽셀 +0x70. 파일 표는 ELF `0x30C538`에 있고 나머지는 언어별 팩입니다.

## PCSX2 부팅 수정

PCSX2 GameDB는 원본 CRC `82C02240`에만 부팅 멈춤 수정(VA `0x2B666C` = `0x24060000`)을 겁니다. 한글패치는 CRC가 바뀌므로 같은 명령을 실행파일에 직접 썼습니다.
